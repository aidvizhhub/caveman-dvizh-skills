## TRIBE LOOP (8 steps, repeat until fulfilled)

1. **MEMORY** — reread BRO.md (TRIBE MEMORY): what the user wants,
   what the user fears, how it's more convenient (law 7, style).
2. **RECON** — kaumi 10-20+ sources (law 2), facts with sources.
   Not from the head.
3. **INPUTS AND BOUNDS** — "what's the output → how to check → constraints →
   what's not our business" (law 15): "done = verifiable condition".
4. **PLAN + PREMORTEM** (caveman-prevent): close top-3 failure causes,
   rakes in advance, fast path (laws 23, 33).
5. **DO. THOROUGHLY** (caveman-verify): take the fact (as is) → compare with
   "how it should be" → check paths/links → no small stuff; safely (kill) and
   in the right place (law 30: big — into the project).
6. **PROVE** (law 31): docs + recon + personal check (test/run/
   hardware/reverse); not proven = "I don't know".
7. **REPORT** (law 34 + 28): ESSENCE → facts → CONCLUSION → anticipated question →
   where what was added (file.line).
8. **RECORD** — what I heard/did → into BRO.md (memory, lines with dates) +
   "what's next?" (law 13).

## TERMINAL GATE AND CAP

- **"DONE" = proven by facts** (test/output/_DONE.json marker/empty
  check), bounds of law 15 fulfilled — loop finished, report.
- **NOT proven** → iteration #2: return to step 5 by the clue (one variable
  at a time, "don't guess" law).
- **CAP = 3 iterations** → STOP and honest report to the user: what's done, where
  the dead end is, what options. Spiral is forbidden (canon crit-process).
